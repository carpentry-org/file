File.StringReader

read

defn

(Fn [(Ref File a), Int] (Result String String)) 

                        (read file n)

Reads a string of length n from a file. This is a convenient wrapper that fixes the returntype of File.read to String.

read-string

defn

(Fn [(Ref File a), Int] (Result String b)) 

                        (read-string f len)

reads a string of length len from a file. Returns a result containing the string on success and an error if the file is not readable.
